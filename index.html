캘린더 한눈에 개인정보처리방침

시행일: 2026년 9월 27일

1. 처리하는 정보

본 확장 프로그램은 사용자의 구글 캘린더 일정을 사용자 브라우저 안에서 Google Calendar API(읽기 전용 권한)로 조회하여 화면에 표시하는 기능만 수행합니다.

2. 수집·저장·전송

개발자는 어떠한 개인정보도 수집·저장·전송하지 않습니다. 일정 내용은 개발자를 포함한 어떤 외부 서버에도 보내지지 않습니다.

3. 액세스 토큰

구글 로그인으로 받은 액세스 토큰은 브라우저 세션 저장소에만 보관되며, 브라우저를 닫으면 삭제됩니다.

4. 설정값

카드 표시 지연 시간·너비·글자 크기 설정만 브라우저의 동기화 저장소(chrome.storage.sync)에 저장됩니다. 개인정보는 포함되지 않습니다.

5. 제3자 제공

사용자 데이터를 판매하거나 제3자에게 제공하지 않으며, 확장 프로그램의 단일 목적 외에는 사용하지 않습니다.
